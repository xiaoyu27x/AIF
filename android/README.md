# 汇率看板 Android App

手机端多币种汇率看板。打开后可从系统提供的 ISO 货币清单中搜索、选择任一基准币种和兑换币种，并显示 1 天、3 天、7 天、1 个月、3 个月、半年、1 年及 2 年的 K 线走势。界面提供市场牌价/银行买入价、现汇/现钞选择。

市场牌价来自公开汇率参考数据；应用在前台时每分钟刷新一次。银行买入价与现汇、现钞的实际报价取决于具体银行、地区和渠道，项目不会以市场价冒充银行报价；接入目标银行的授权 API 后即可启用该模式。

用 Android Studio 打开此目录，完成 Gradle 同步后选择 `app` 运行，或执行 **Build > Build APK(s)**。首次构建需要联网下载 Android Gradle 插件。
